Switch to Colab. The notebook: (1) starts a deliberately naive OpenAI-compatible server around transformers.pipeline, one request at a time; (2) fires 1, 8, 32, 64 concurrent streaming clients and records TTFT, throughput and failures; (3) stops it, starts vLLM with the same model, repeats; (4) prints this table and a plot, and runs one extra 64-client wave while polling vLLM's /metrics, so you can watch "requests running" climb to 64. Fill the blanks with the printed numbers, then compare with the predictions from the previous slide. Colab's T4 has 320 GB/s of bandwidth, so absolute numbers are smaller than on the judge — the ratio is the point. Rehearsal on a Colab T4 (2026-09-19, seminars/runs/): pipeline 21 / 21 / 18 / 19 tok/s at 1 / 8 / 32 / 64 clients, 19 of 32 and 51 of 64 clients gave up at 60 s; vLLM 49 / 315 / 922 / 1459 tok/s, p95 TTFT 0.32 s at 64, no failures — about 77× at 64 clients. Expect numbers in that range live; vLLM start-up takes ~2 min, install ~5 min — start the notebook before the lecture.
