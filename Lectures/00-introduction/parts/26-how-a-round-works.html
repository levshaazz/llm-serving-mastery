The snapshot is what makes the deadline real: at Thursday 23:59 Moscow time (UTC+3) the judge resolves every student's round-NN tag to a commit SHA and measures exactly those commits — re-tagging after the deadline has no effect. Then a clean checkout, start-up (30-minute window: dependency install, weight download, engine start), a one-request smoke test, the quality gate, the speed runs, and publication with the full logs so that every failure is explainable. The same code runs in Colab: you can put your own repository through the identical pipeline before Thursday.
