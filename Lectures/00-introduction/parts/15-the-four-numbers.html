The trade-off you will live in

Bigger batches raise throughput and usually hurt TTFT and TPOT. Every configuration choice in this course is a point on that curve.

Define these now so the demo reads naturally. Plus two non-negotiables we always report: failed requests (timeouts, OOM) and quality — a fast server that answers wrong is not a server.
