The notebook baseline is valuable—and deliberately incomplete

Starting point

It gives us

  • correct model loading
  • a reproducible prompt
  • token and timing instrumentation
  • a single-user reference

It lacks

  • network protocol and isolation
  • cross-request scheduling
  • admission control
  • production lifecycle and telemetry
The baseline is not mocked or dismissed. We need it because later speedups need a common reference. But it is not evidence of production capacity.
