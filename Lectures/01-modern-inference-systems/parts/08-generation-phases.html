Generation has two computationally different phases

Prefill / decode

Prefill

Process the prompt in parallel, build state for all prompt tokens, produce the first next-token distribution.

Grows with input length.

Decode

Generate one new token per sequence step, reusing cached state and repeatedly reading model data.

Grows with output length.

Stay qualitative here. Prefill tends to expose parallel compute; decode tends to be constrained by repeated memory movement at small batches. Topic 2 will derive memory and roofline consequences and show exceptions.
