Name latency before optimizing it

Metrics
TTFT

request sent → first output token observed

TPOT

time per output token after the first; state aggregation convention

ITL

gap between successive streamed tokens or chunks

E2E

request sent → terminal response observed

TPOT is often computed as (E2E − TTFT)/(output_tokens − 1), but tools differ. ITL may be chunk rather than token based. Never compare labels without definitions and timestamps.
