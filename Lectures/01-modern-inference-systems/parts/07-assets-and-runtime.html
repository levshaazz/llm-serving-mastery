“The model” is a versioned bundle, not one file

Artifact boundary

Weights

dtype, quantization, shards, revision

Tokenizer

vocabulary, normalizer, chat template

Configuration

architecture, context, generation defaults

Runtime

framework, kernels, CUDA, driver, hardware

Pin all four before comparing results.
A tokenizer or chat-template change can alter token counts and outputs without changing weights. A runtime change can alter latency without changing model artifacts. This is why “same model name” is insufficient provenance.
