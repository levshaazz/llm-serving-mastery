A benchmark begins with a workload specification

Required fields
Artifactsmodel revision, tokenizer, chat template, runtime versions
Inputsdataset/source, prompt-token distribution, request parameters
Outputscap or distribution, stop conditions, deterministic settings
Loadopen/closed loop, arrival rate or concurrency, duration, warm-up
SuccessTTFT/TPOT/E2E percentiles, throughput, errors and explicit SLO
If one field is absent, another engineer may reproduce the code but not the experiment. Token distributions are more portable than character counts.
