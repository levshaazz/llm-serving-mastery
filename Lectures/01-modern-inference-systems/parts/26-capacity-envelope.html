A deployment has a capacity envelope, not one capacity number

Inputs
$$\text{capacity} = f(\text{system},\ \text{workload},\ \text{SLO})$$
System
hardware + model + runtime
Workload
prompts + outputs + arrivals
SLO
the boundary that defines useful capacity
This is why public tokens/s numbers rarely transfer directly to a product. We will build one point on this envelope in the seminar, then expand it across concurrency and configurations later.
