Startup and steady state are separate experiments

Lifecycle

Cold path

  • resolve and download artifacts
  • load weights and allocate memory
  • compile, autotune or capture graphs
  • become ready

Warm path

  • artifacts cached
  • engine initialized
  • kernels warmed
  • requests reach steady state
Cold-start economics matter for deployment and autoscaling, but mixing the first request into a steady-state latency average makes both questions hard to answer. Report both explicitly.
