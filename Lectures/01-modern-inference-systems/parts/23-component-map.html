A minimal production map separates policy from execution

Responsibilities

Gateway

identity, validation, quotas, request IDs

Router

model and replica placement

Scheduler

queue and execution policy

Workers

tokenization, model execution, streaming

Artifact store

immutable model bundles

Telemetry

logs, metrics, traces and cost

This is a responsibility map, not a mandated microservice diagram. In a small deployment, gateway, router and scheduler may live in one process. Their policies still need distinct tests.
