Autoregression is serial across generated tokens—not inside the whole GPU.

Start from the dependency that cannot be scheduled away: token t+1 is unknown until token t has been selected.

The GPU does not receive “text”

Boundary before the forward pass

CPU-side contract

GPU-side input

Tokenizer time is real user time, but it is not transformer compute. Preserve the boundary when profiling.

False shortcut

“One token at a time means one GPU operation at a time.”

Each token step traverses billions of parameters through many parallel kernels. The serial constraint is between generated positions.
